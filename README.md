# UMBRA Pro

Glassy steel AI workspace — chat, projects, multi-agent Labs.

## Features

- Multi-provider keys (OpenRouter, OpenAI, Anthropic, Gemini, xAI + more)
- Chat with reasoning levels + model context sizes
- Projects
- Custom backgrounds (local image + presets)
- Modes: Chat · Code · Solo agent · Group agent · Labs
- Labs: authorized recon (depth tiers, FIND1, up to 128 agents) + JB model lab

## Setup

```bash
npm install
npm run dev
```

Keys stay in browser localStorage only.

## Deploy

Import **Foxxed909/umbra-pro** in Vercel (Framework: Next.js).
